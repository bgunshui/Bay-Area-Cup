# 学术汇报图表设计参考

本次按用户要求搜索并参考公开学术汇报范例，采用“明确标题、图表解释模型与结果、正文只保留必要标签”的方式重构。未复制示例的图片、实验数据或机构标识。

2026-10-09大修进一步参考：

- [Assertion–Evidence：研究汇报范例](https://www.assertion-evidence.com/research_models.html)：以核心论点组织每页，主要用图形支撑技术信息，来源和推导细节移至讲稿及问答。
- [CVPR 2024：Sparse Semi-DETR报告](https://cvpr.thecvf.com/media/cvpr-2024/Slides/30138.pdf)：参考其“动机→方法模块→实验比较”的内容组织。仅借鉴汇报结构，不复制算法、图示或实验值。

- [MIT / Broad Communication Lab：Slideshow](https://mitcommlab.mit.edu/broad/commkit/slideshow/)：每页聚焦一个结论，以图形替代长段文字，细节放入讲述。
- [MIT AeroAstro：Slide Design](https://mitcommlab.mit.edu/aeroastro/commkit/slide-design/)：参考其简化前后对照范例，减少包围框与多余信息，保留清楚的阅读方向。
- [MIT / Broad：Figure Design](https://mitcommlab.mit.edu/broad/commkit/figure-design/)：依据图表要表达的关系选择类型；候选演进用曲线，配置权重用条形图，训练与部署用流程图。
- [MIT 21W.035：PowerPoint Presentation Tips](https://ocw.mit.edu/courses/21w-035-science-writing-and-new-media-communicating-science-to-the-public-fall-2016/68f91d169741f8b142aec4ab278718dd_MIT21W_035F16_PowerPointTips.pdf)：参考其图表简化示例，直接标注数据、轴和单位，减少读图时的往返。

曲线及数值图仅使用已有记录、最终分量CSV和确定公式：双赛道候选AUC、真实集成与教师权重、软标签和置信权重函数、最终分量相关性、先验OOF及双赛道AUC。鲁棒性仅画训练策略与评测方向，未生成无数据支持的攻击曲线、分组AUC或ROC曲线。

模型架构、训练流程和应用流程为本项目重绘；图像与文本分别建模，流程连接不表示联合多模态推理。
