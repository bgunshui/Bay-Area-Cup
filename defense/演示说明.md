# 双赛道答辩演示说明

## 打开与文件

从Git仓库取得本目录后，用 Microsoft Edge 或 Chrome 打开 `defense/index.html`；无需安装依赖、登录或连接网络。HTML 已内联 Noto Sans SC／Inter 字体、Lucide 图标及 Motion 运行资源，可单独复制使用。仓库仅维护解压后的材料，不生成或上传压缩包。

主讲为14页，计划13分20秒，距15分钟上限留1分40秒缓冲；后续5分钟用于评委问答。自动翻页初始关闭，建议现场保持关闭。请先按逐字讲稿排练，页面内提词卡用于提醒关键结论，不代替完整逐字稿。

## 普通演示

按左右方向键／PageUp、PageDown 翻页；Home 回首页，End 到尾页。Esc 打开总览，点击缩略图跳转。底部导航点也可选页。将鼠标移到右下角可显示快捷控制；正式页面默认隐藏这些辅助小字。`B` 在普通页面切换低性能模式；该模式停用背景动效，文字、图表和流程仍完整显示。浏览器 `F11` 可进入或退出全屏。

## 演讲者与观众屏

1. 点击右下“演讲模式”，或按 `P`。当前窗口显示当前页、下一页、提词与计时，新窗口为观众屏。如浏览器拦截弹窗，允许此文件打开弹窗，再点击“重新打开观众屏”。
2. 双屏使用系统“扩展”显示，将观众窗口拖至投影屏，在该窗口按 `F11` 全屏；演讲者窗口留在笔记本。单屏排练也可使用两个窗口。
3. 顶栏应显示“观众屏 · 已同步 · 第N页”。该提示表示浏览器页面同步；投影是否正常仍需现场目视确认。关闭观众窗口后，点击“重新打开观众屏”，会恢复到当前讲述页。
4. 点“开始计时”，翻页会自动记录本页用时；可暂停、继续和重置。计划总时长800秒，各页时长见下表。点“排练”可记录一轮排练用时。
5. 备注框可编辑，按稳定页面ID保存在本机浏览器内。换浏览器或换文件路径不会带走本机备注；原始提词已内置在HTML中。需要正式修改时，请一并修改讲稿与提词并重新核对数字。
6. 演讲者模式中的 `Esc` 打开宫格；`L` 激光、`C` 圈选、`X` 清除标记；`B` 观众黑屏、`W` 观众白屏、`F` 冻结／恢复观众页。此模式的 `B` 与普通模式的低性能快捷键用途不同。编辑备注时，方向键优先用于编辑。
7. “检查”可检查页面同步、备注、计划、字体与全屏的软件状态。“设置”可调整布局和自动翻页；现场演示使用手动翻页。退出演讲者模式会通知观众屏结束。

## 讲述口径

图像AUC **0.918887** 是仓库成绩记录，文本AUC **0.981301** 为交接确认，均未在本次用官方标签重算；AUC不称准确率。第6页相关系数描述最终图像分量的预测互补性；服务输出与离线CSV的排序一致性属于另外的检查，二者均不能替代检测AUC。

图像服务视觉骨干／LoRA和输入使用fp16，分类头使用fp32；离线CSV是bf16 autocast批量路径。图像0.236秒／张来自200张顺序HTTP共47.2秒；文本0.68秒／条来自5条短输入（含空串）的历史宿主GPU记录。两组输入、环境不同，不作普适速度比较或并发吞吐推算。

训练增强、已有成绩与待验证能力已分别表述。当前没有独立未见生成器、攻击强度、领域与长度分组AUC；尺寸先验依赖分布。LoRA降低新增训练参数，完整推理仍需大骨干与多分量前向。应用页是试点设想，未补写客户或收益。

## 项目技能与可编辑性

指定skill随仓库保存在根目录 `.agents/skills/guizang-ppt-skill`，固定上游提交 `c91369c449d34755d320a8b81d0734000d99d1ab`，保留 `SKILL.md`、`assets/`、`references/`、`scripts/` 与许可证。使用了Swiss模板及锁定布局，最终14页含12种注册布局；HTML本身是可编辑源码，后续正式内容修改集中在 `defense/src/`，通过脚本重建演示。

最终风格采用白底正文、深蓝强调、清晰字重和收敛标题，去掉ASCII背景及装饰性英文页眉。封面和收束页沿用白底与深蓝强调。入库后的版本由Git提交历史管理；本地制作缓存、旧备份及压缩包不入库。

主讲内容已改为面向评委的学术汇报：去除复核、交付和证据等级叙事，删除重复页眉、来源脚注及装饰性小字。2026-10-09大修重新绘制训练来源矩阵、三槽汇流与ECDF、最终分量相关性、先验OOF、六教师筛选、自训练闭环、双函数与加权BCE、双基座模型树，以及排名和logit两条推理链。AUC来源集中在后台索引与问答，观众页只保留评价对象、必要的测试条件及科学结论的适用范围。历史AUC候选、公式图和融合参数的解读见 `图表说明.md`；逐页来源集中留在证据索引，供问答查询。设计参考见 `设计参考.md`。

技术事实固定在 `bgunshui/Bay-Area-Cup` 提交 `c11fa520f2f73d705e83cb3f40a6a214f8cc7f31`，图像精度勘误已纳入正文、讲稿和问答。证据链接固定到该提交。演示目录不改写既有技术报告、模型文件与实验数据。

使用Chrome／Edge进行正式播放；其他浏览器尚未实测。2026-10-09大修的历史浏览器验收以 `验收记录.json` 中的 `inputSha256` 绑定HTML；当时通过离线 `file://` 的28项交互与页面检查。本次入库保留HTML原始字节与测试记录，没有把路径迁移记作重新运行浏览器测试。真实投影仪、扩展屏与线缆需在现场走一次演前检查。

## Git维护

以下命令从仓库根目录执行：

```powershell
python defense/scripts/build.py --final
python defense/scripts/verify_materials.py
python defense/scripts/update_checksums.py
```

同步修改 `defense/src/` 中的页面与提词、逐字讲稿及评委问答，随后重建并检查材料，再更新SHA清单。原始验收记录保留其测试时间与HTML哈希；HTML发生变化后，旧记录只代表旧版本，需要另做浏览器交互检查，不能作为新版本的实测结果。当前离线字体为已有文本的字符子集；新增未覆盖汉字时须补充字体子集。确认修改后使用Git提交并推送，版本回退也通过Git完成。

相关性统计可从仓库根目录执行 `python defense/图表/重算分量相关性.py`；默认读取固定技术提交并更新 `defense/图表/图像分量相关性数据.json`。它仅重算已有CSV的统计，不运行模型或修改实验源文件。
