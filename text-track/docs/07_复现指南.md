## A. 只复现"分数"(不需要 GPU,分钟级)

这一步验证**离线融合链路**能还原提交文件:

```bash
pip install numpy scipy pandas

python - <<'PY'
import numpy as np, pandas as pd
from scipy.stats import rankdata

def rank01(x):
    return rankdata(np.asarray(x, np.float64), method="average") / (len(x) + 1.0)

# 15 个适配器的离线预测(五折均值)
p4  = np.load("evidence/离线预测/14b_p4_replay_rank01.npy")   # 已是 rank01
r3a = np.load("evidence/离线预测/7b_r3a_replay_raw_mean.npy")
r3b = np.load("evidence/离线预测/7b_r3b_replay_raw_mean.npy")

score = rank01(0.90 * rank01(p4) + 0.10 * (rank01(r3a) + rank01(r3b)) / 2)
print("融合分数前 5 个:", score[:5])
print("与提交文件的排序一致性与 AUC 需平台标签,本地仅能验证排序")
PY
```

**注意**:本地**没有复赛标签**,所以无法独立算出 AUC。
但我们验证过:用本地中间结果重建的分数与平台实际收到的提交文件
**排序 100% 一致、数值最大差 1.1×10⁻¹⁶** —— 即这条链路就是产生 0.981301 的那条。

复现脚本:[`code/fusion/p97_p4_7b_sweep.py`](../code/fusion/p97_p4_7b_sweep.py)(生成提交)
与 [`p101_verify_7b2.py`](../code/fusion/p101_verify_7b2.py)(校验)。

## C. 从零重训(需要 GPU 集群 + 竞赛平台提交额度)

### C1. 整体流程图

```
① 官方 1000 条 → LoRA 微调 1.5B / 7B / 14B
        ↓
② 48 个异构分支 → rank 融合 → 教师(0.978284)
        ↓  对 20000 条测试样本打软伪标签
③ 第一轮自训练:14B 学生(官方真标签权重 2.0 + 软伪标签)
        ↓  复赛反馈 0.979964
④ 多随机种子自训练 → seed1 / seed2 / seed3
        ↓  双 seed 集成 0.980896;纯 seed2 0.981069
⑤ 异构集成:0.90 × 14B(p4 五折)+ 0.10 × 7B(r3a/r3b 十折)
        ↓  复赛反馈 0.981301  ★
```

### C2. 关键脚本对照

| 阶段 | 脚本 |
|---|---|
| 初始监督微调 | `code/training/p42_self_train.py`、`p43_14b_p2.py` |
| 伪标签构造 | `code/fusion/mk_pseudo_best.py`、`mk_pseudo_v2.py`、`p73_mk_pseudo_v3.py` |
| 教师融合(48 分支) | `code/fusion/p4_fusion.py`、`p40_fus_lgb.py` |
| 多种子训练 | `code/training/p25_seedens.py`、`p26_seedens2.py`、`p27_seed2_070.py` |
| 权重扫描与提交生成 | `code/fusion/p87_p4_only.py` … `p97_p4_7b_sweep.py` |
| 结果核验 | `code/fusion/p101_verify_7b2.py` |
| 特征与外部检测器 | `code/features/infer_*.py`、`qwen*_oof.py`、`text_ppl.py` |

### C3. 复现时最容易踩的 3 个坑

1. **`peft 0.20.0` 需要先导入 `torch.distributed.tensor`**
   它是惰性子模块,不预加载会抛
   `AttributeError: module 'torch.distributed' has no attribute 'tensor'`。
   见 `code/docker_submit/server_dual_v4.py` 开头。
2. **Python ABI 必须与 wheel 一致**
   早期用过一批 **cp312** 的编译产物而解释器是 **Python 3.10**,
   报 `Failed to load PyTorch C extensions`。所有 wheel 必须是 **cp310**。
3. **不要用 `softmax` 当分数**(见下文"数值稳定性")。

---

## D. 数值稳定性(务必遵守)

| 分数形式 | 并列在最大值的样本比例 |
|---|---|
| `softmax(logits)[:,1]` | **49.5%**(约 45% 完全并列在 1.0) |
| `logits[:,0]`(正确做法) | **0.10%** |

AUC 只看排序,一旦大量样本并列在 1.0,排序信息就被丢弃。
