## D）权重结构审计的历史结果与局限

原报告记录 27 个 safetensors 文件：15 adapter，加 14B 八个和 7B 四个基座分片；合计 5,093 个 tensor。分片 index 记录分别为 579 与 339 条权重映射，未记录缺失。

`audit_BCD_image.py` 检查头 JSON、字段存在、相邻数据区间连续和预期文件总大小，比较 index 所列分片名称。这是结构检查，不是逐 tensor 内容校验或模型 AUC 验证。脚本有以下盲区：

- 未验证 dtype/shape 对应的字节数与 data_offsets 匹配，也未要求首区间从零起始。
- 头 JSON 解析失败增加 `bad` 后继续，但不一定加入最终 `problems`；因此最终退出码可能遗漏该失败。
- 缺失 requirements 时，对 pin 的检查不会加入问题列表。

不能仅凭“退出 0”宣布所有权重和依赖均完整，更不能把文件可解析称为模型行为正确。
