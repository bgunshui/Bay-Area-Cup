# 文本赛道 · 关键实验结果

> 全部数字来自**官方复赛反馈(AUC)**——复赛测试集无标签,本地无法独立计算 AUC,
> 因此除特别标注外,表中均为平台返回成绩。
> 官方 1000 条样例的验证分数**不用于选型**(五折后每折仅 200 条,噪声 ±0.01)。

## 一、主结果:递进消融(AUC 从 0.9615 到 0.981301)

| # | 实验 | 复赛 AUC | 相对上一行增益 |
|---|---|---|---|
| 1 | 纯 14B seed1 监督微调 | 0.9615 | 单分支基线 |
| 2 | 48 分支异构融合(LLM 似然 / 隐藏态 / 公共检测器 / 风格特征 / 近邻) | 0.978284 | **+0.0168** |
| 3 | 第一轮伪标签自训练(14B seed1) | 0.979964 | **+0.0017**(域自适应) |
| 4 | 双 seed 集成(seed1 + seed2) | 0.980896 | **+0.0009**(多种子) |
| 5 | 纯 seed2(最优单一模型,**中间结果**) | 0.981069 | 种子间差异达 0.0011 |
| 6 | **★ 最终提交:0.90 × 14B(p4 五折)+ 0.10 × 7B(r3a/r3b 十折)** | **0.981301** | **+0.0002**(异构混合) |

**最终提交成绩 = 0.981301(复赛文本榜第 4 名)。**

### 三个可复述的方法论结论

1. **迭代自训练有效**:用融合模型对无标签目标域打软标签 → **+0.0017**(单项增益最大)
2. **多随机种子集成有效**:同配置不同种子 → **+0.0009**
3. **异构集成优于同构集成**:

| 组合 | 分支间相关 | AUC |
|---|---|---|
| 两个 14B 种子(同构) | 0.996 | 0.980896 |
| **14B + 7B(异构)** | **0.995** | **0.981301** |

→ **相关性更低的一方带来增益**,错误模式更互补。

### 一个反直觉的发现

**伪标签的"信息多样性"比"分数高低"更重要**:
用 48 分支融合(**0.9783**)当教师训出的学生,优于用更强的纯 14B 集成(**0.9809**)当教师训出的学生。

## 二、最终方案的确切计算式

### 2.1 离线提交(0.981301 那一次,`submit_p4_90_7b2_10.csv`)

```python
p4   = mean_{fold=1..5}  rank01( logits_14B_p4_fold )   # 每折先在 20000 条内做全局秩归一化,再按折平均
r3a  = mean_{fold=1..5}  rank01( logits_7B_r3a_fold )
r3b  = mean_{fold=1..5}  rank01( logits_7B_r3b_fold )
ens7 = ( r3a + r3b ) / 2
score_offline = rank01( 0.90 × p4 + 0.10 × ens7 )       # rank01(x) = rankdata(x) / (N+1),N = 20000
```

**可复现性验证**:用本地留存的中间结果逐位重建,与提交文件
**排序完全一致、数值最大绝对差 1.1×10⁻¹⁶**(浮点舍入量级)。

### 2.2 线上镜像(逐条请求,只能用逐样本算子)

```python
score_image = 0.90 × sigmoid( mean_{fold=1..5}  logits_14B_p4_fold )
            + 0.10 × sigmoid( mean_{fold=1..10} logits_7B_r3a/r3b_fold )
```

### 2.3 两者差异(方法学限制,非缺陷)

| # | 差异 | 离线提交 | 镜像 |
|---|---|---|---|
| A | 折间聚合所在的空间 | **秩空间**(每折先全局排名再平均) | **logit 空间**(先平均,最后一次非线性映射) |
| B | 跨模型融合所用的表示 | **全局排名**(强制均匀分布,标准差恒 0.2887) | **sigmoid 概率**(保留各模型置信度尺度) |

`rank01` 会丢弃分数尺度、把输出强制为均匀分布,而 `sigmoid` 保留尺度,
因此同一个 0.90/0.10 权重在两种表示下的实际相对影响不同 —— 这就是线上分数偏差的来源。

## 四、综合分与赛道权衡

综合分 = e^(4×AUC_text) + e^(4×AUC_image)

```
文本 e^(4×0.981301) = 50.6634
图像 e^(4×0.918887) = 39.4703
                     ────────
                合计 = 90.1337   → 总榜第 6 名
```

**边际收益**(因为 d/da e^(4a) = 4 e^(4a),基数越高越划算):

| 提升 | 综合分增益 |
|---|---|
| 文本 AUC +0.001 | **+0.2031** |
| 图像 AUC +0.001 | +0.1582 |

→ **文本赛道的边际效率是图像的 1.28 倍**。

## 五、训练配置(LoRA / 自训练)

| 项 | 配置 |
|---|---|
| 基座 | Qwen2.5-14B-Instruct / Qwen2.5-7B-Instruct(bf16) |
| 微调 | LoRA:r=16, α=32, dropout=0.05,target = q/k/v/o_proj |
| 分类头 | `score`(2 类,新初始化) |
| 损失 | `BCEWithLogitsLoss(logits[:,0], target) × weight` |
| 优化器 | AdamW,lr=5e-5,weight_decay=0.01,linear warmup 10% |
| 训练 | 2 epochs,seq_len=512,batch=2(不启用梯度检查点) |
| 交叉验证 | 官方 1000 条 5 折(SEED 20260823);复赛数据不参与验证 |
| 预测 | `logits[:,0]`(AI 方向);方向保护:AUC<0.5 自动翻转 |

**伪标签构造**(核心):

```python
rank = rank01(s)                          # 排名归一化到 (0,1)
soft = sigmoid(4 × (rank − 0.5))          # 软标签,范围 (0.08, 0.92)
conf = clip(4 × |soft − 0.5|, 0, 1)       # 置信度权重
```

每折训练样本构成:

| 数据 | 数量 | 标签 | 损失权重 |
|---|---|---|---|
| 官方训练折 | 800 | **真实硬标签** | **2.0** |
| 复赛测试集 | **20000** | **软伪标签** | `conf` |

## 六、数值稳定性:一个被低估的关键点

| 分数形式 | 并列在最大值(`frac==max`)的样本比例 |
|---|---|
| `softmax(logits)[:,1]`(早期版本) | **49.5%**(其中约 45% 完全并列在 1.0) |
| `logits[:,0]`(最终版本) | **0.10%** |

AUC 只取决于排序 —— 一旦近一半样本并列在 1.0,排序信息被大量丢弃。
这是"看似小事、实则决定 AUC 上限"的工程判断。
