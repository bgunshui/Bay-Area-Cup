## 三、正确的最终公式

记r为平均秩除以N+1。根据[p97](../code/fusion/p97_p4_7b_sweep.py)：

```python
p4 = r(load("lora14b_p4_replay.npy"))
a  = r(load("lora7b_distill_r3a_replay.npy"))
b  = r(load("lora7b_distill_r3b_replay.npy"))
offline = r(0.90 * p4 + 0.10 * (a + b) / 2)
```

根据[server_dual_v4](../code/docker_submit/server_dual_v4.py)：

```python
online = 0.90 * sigmoid(mean(14B_p4_5_logits)) \
       + 0.10 * sigmoid(mean(7B_r3a_r3b_10_logits))
```

7B是两组各五折，不是十折交叉验证。两条公式在折聚合、跨模型表示方面不同；服务分数未经概率校准。

## 四、本次复算数字

按提供的数组行序与CSV比较；数组无id，缺原文，行序来源尚不能独立验证。

| 比较对象 vs CSV | Spearman | 平均秩不同的行数 | 最大绝对差 |
|---|---:|---:|---:|
| 旧README raw_mean近似式 | 0.9999998013 | 9341 | 0.0093495325 |
| fusion_offline_submitted | 0.9999995877 | 18062 | 0.0019999000 |
| fusion_online_image | 0.9998697006 | 19369 | 0.1618774523 |

三组raw_mean按服务公式计算，和冻结online最大差约1.25e-9。结果高度接近，不是逐位一致。精确离线链缺7B两组replay.npy及逐折raw；旧“排序100%一致、最大差1.1e-16”不能由当前文件重现。

本次CSV与冻结online严格反序218292对，单侧并列变化279对，合计218571 / 199990000 ≈ **0.10929%**。独立Fenwick计数经小例穷举和SciPy Kendall tau-b交叉核验；tau-b两种实现均为0.9978162717686663。

这不是AUC差。若**额外假设**复赛每类各10000，且所有受影响对都跨类，计入并列半分的保守上界为(218292 + 279/2)/1e8 = 0.002184315。仓库没有复赛标签，不能确认该假设，也不能预测实际差值或翻转方向随机。旧204591对与0.0020结论不作为已核验事实。

## 五、训练与验证的正确口径

p43默认batch=4、梯度检查点开启、长度512 tokens；官方验证AUC用于选checkpoint，p4_fusion用OOF AUC选融合权重。不能说样例完全不参与选型。软标签sigmoid(4(rank-0.5))理论范围约0.1192～0.8808，conf是启发式损失权重。

旧softmax饱和45%、49.5%→0.10%缺对应完整原始输出；不当作复测数字。GPU的70.1秒启动、0.68秒推理仅来自团队报告中的五条短文本，缺完整日志与实际Docker复核；未覆盖最长输入或并发负载。

比赛规则、数据删除、未使用外部API等历史行为不能仅凭当前源码认证。需要原始资料后再核对，当前不预判合规结论。
