## 方案一句话

> **0.90 × [Qwen2.5-14B-Instruct + p4 五折 LoRA]  +  0.10 × [Qwen2.5-7B-Instruct + r3a/r3b 十折 LoRA]**
> 在**三轮伪标签自训练**得到的领域自适应模型上做**异构分数级集成**。

```
score = 0.90 × sigmoid( mean₅  logits_14B_p4 )
      + 0.10 × sigmoid( mean₁₀ logits_7B_r3a/r3b )
```

## 三个最值得在答辩里讲的点

1. **官方样例不能用来选模型,所以只能靠"无标签自训练"破局**
   官方只有 1000 条标注,五折后每折仅 200 条验证样本,**AUC 噪声约 ±0.01** ——
   而我们的方案间差异只有 0.0002~0.0017。用样例选型必错。
   于是改用「48 分支异构融合 → 打软伪标签 → 训 14B 学生」三轮迭代,
   复赛反馈从 **0.9615 一路推到 0.981301**。

2. **伪标签的"信息多样性"比"分数高低"更重要**
   用 48 分支融合(**0.9783**)当教师训出的学生,**优于**用更强的纯 14B 集成(**0.9809**)当教师。
   这与直觉相反,是我们实测出来的结论。

3. **异构集成 > 同构集成**(可直接引用的对比)

   | 组合 | 分支间相关 | AUC |
   |---|---|---|
   | 两个 14B 种子(同构) | 0.996 | 0.980896 |
   | **14B + 7B(异构)** | **0.995** | **0.981301** |

   相关性更低的一方带来增益 —— 错误模式更互补。

## 复现最快路径(不需要 GPU、不需要权重)

```bash
python - <<'PY'
import numpy as np
from scipy.stats import rankdata
def rank01(x): return rankdata(x, method="average") / (len(x) + 1.0)

p4  = np.load("evidence/离线预测/14b_p4_replay_rank01.npy")
r3a = np.load("evidence/离线预测/7b_r3a_replay_raw_mean.npy")
r3b = np.load("evidence/离线预测/7b_r3b_replay_raw_mean.npy")
score = rank01(0.90 * rank01(p4) + 0.10 * (rank01(r3a) + rank01(r3b)) / 2)
print(score[:5])
PY
```

本仓库用本地中间结果**逐位重建**过这份提交:**与提交文件排序 100% 一致、数值最大绝对差
1.1×10⁻¹⁶** —— 即这条链路就是产生 0.981301 的那条。
(本地无复赛标签,因此无法独立算出 AUC。)

需要跑完整推理:见 [`docs/07_复现指南.md`](docs/07_复现指南.md)。

## 与图像赛道的口径对照

| 项 | 图像赛道 | 文本赛道 |
|---|---|---|
| 复赛 AUC | 0.918887 | **0.981301** |
| 综合分贡献 e^(4·AUC) | 39.4703 | **50.6634** |
| 交付镜像大小 | 约 19 GB | 约 50 GB |
| 单条推理 | 0.31 秒 | 0.68 秒 |
| 线上↔离线一致性 | 逐图 ECDF,**恒等于**全局 rank | 全局 rank → 逐样本 sigmoid,**排序相关 0.99987** |

> 两条赛道都遇到了"**提交用的是全局 rank,而交付要求逐条 `POST /predict`**"的同一个矛盾。
> 图像赛道用**逐图 ECDF** 做到了完全等价;文本赛道因融合输入也要做秩归一化,
> 只能退到逐样本 sigmoid,产生了 0.1023% 的排序差异(AUC 严格上界 0.0020)。
> **答辩时可以把这个对比作为一个亮点讲**:同一个方法学问题,两条赛道给出了不同强度的一致性方案。
